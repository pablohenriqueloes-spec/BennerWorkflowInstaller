# assets/

- `benner-logo.png`: aproximação estilizada da marca, vinda do pacote original. **Não é o arquivo oficial da Benner.** Para usar o logotipo institucional, substitua este arquivo (somente se houver autorização para versioná-lo).

O script procura `benner-logo.png` primeiro ao lado de `BennerWorkflowInstaller.ps1` e, se não encontrar, em `..\assets\`. Sem nenhum dos dois, mostra o nome "benner" estilizado no cabeçalho.
